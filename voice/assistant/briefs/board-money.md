# Brief: board-money — 状态板的「消耗」写钱，不写工具次数

## Why (the user's yardstick: 每个成功任务的总成本; and what the board says tonight)
`cost` (merged 1db2344) can now say what a job cost: 72 jobs, 78 rounds, **$249.10**, dearest `phone-console` $10.26.
`run.mjs` writes it into every round's `history[].cost` (a9e2323). But the board's 「消耗」 section still counts tool
calls — `- 今天：12 个单、16 轮、631 次工具调用` — which is a proxy for cost, not cost. The one section the user
reads to answer 「今晚花了多少」 answers a different question.

## What to build

### 1. `Board.Job` carries the history, so the board can add it up
`src/xyz/erapi0neer/xingyi/agent/Board.java`: `Job` gets a `public final org.json.JSONArray history` field and a
constructor overload that takes it (the existing 11-argument constructor stays, delegating with `null`, so no call site
outside your files has to change). Java is still pure: `org.json` only, no `android.` import.

### 2. The 「消耗」 section, in both files
`Board.java`'s `cost(...)` and `board.mjs`'s `costLines(...)` keep their existing first bullet **word for word**
(`- 今天：… 次工具调用（按每轮 \`history[].tools\` 汇总）；最费的一次：\`<id>\`（<n> 次）`, the 「没有单跑过。」 case,
the 「- 上限：同时在跑最多 」 bullet) — `BoardChecks` pins those strings and the user reads them — and **insert one money
bullet between the 今天 bullet and the 上限 bullet**, then the dearest list when there is one:

```
- 今天：12 个单、16 轮、631 次工具调用（按每轮 `history[].tools` 汇总）；最费的一次：`verify-durable`（119 次）
- 花在模型上：$249.10（72 单；3 单没有成本，合计是下限）
- 最费的几单：
  - phone-console $10.26 (1 轮)
  - verify-durable $9.94 (5 轮)
- 上限：同时在跑最多 2 单
```

- The money line is **`spend()`** (already in `tools/cost/cost.mjs`, committed 19bc748) for the JS side, and a Java
  mirror in `Cost.java` — `public static String spend(java.util.List<org.json.JSONObject> jobs)` — with the **same
  wording**, because `CostChecks` compares the two files' literals. Read `cost.mjs`'s `spend()` first: the rules are
  (a) no jobs → 「没有单跑过。」, (b) every job unmeasured → 「算不出来（N 单都没有记成本）」, (c) otherwise `$x.yz（N 单`,
  plus 「；K 单没有成本，合计是下限」 when K>0, then `）`. A null total is never `$0.00`.
- The dearest list is `dearestLines(jobs, 5)` / `Cost.dearest(jobs, 5)` (both exist), each line indented two spaces
  under a `- 最费的几单：` bullet. Empty string → no bullet at all, not an empty heading.
- The board's jobs are `{id, history}` objects; `board.mjs`'s `normalize()` must pass `history` through (it already has
  the array, it just drops it). The money bullet covers the **same `--since` window** as the 今天 bullet (jobs whose
  `updatedMs >= cutoff`), not all time.
- `board.mjs`'s CLI: when a job's `history` has no `cost` on any round, try `repair(state, resultEvents(<job>/log.jsonl))`
  before deciding it is unmeasured — tonight's older jobs got no `cost` from `run.mjs`, and the board should still be
  able to say what they cost. If `log.jsonl` is missing, leave it unmeasured.

### 3. Checks (`tests/agent/BoardChecks.java` and `tests/agent/CostChecks.java`, you own both)
- `BoardChecks`: the money bullet appears **after** the 今天 bullet and **before** the 上限 bullet; a fixture with
  known costs prints the exact total; a fixture whose rounds carry no `cost` prints 「算不出来」 and never `$0.00`; a
  mix prints the lower-bound sentence; the dearest list is indented and capped at 5; a job outside `--since` does not
  count toward the money bullet; the existing pinned strings are unchanged.
- `CostChecks`: the JS `spend()` and Java `Cost.spend` agree — feed both the same three job shapes (all measured; one
  unmeasured of three; all unmeasured) and compare the sentences byte for byte against the literals in the two files.
- At least 10 new checks in total. The zero case, the unknown case, the mixed case and the dearest indent are the ones
  that will be got wrong; write them first.
