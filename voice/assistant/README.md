# 星仪电视助手

本工程位于 H:\tools\mitv\voice\assistant，包名 xyz.erapi0neer.xingyi，当前版本 0.10.1（versionCode 18）。电视为 MiTV-ASTP0 / Android 9。

主界面右侧的「执行过程」随任务更新。可查看模型和工具调用、等待确认、下载进度、系统回执及核对结果，用遥控器方向键翻看步骤。启动第三方应用后，返回星仪仍可查看上一项任务的记录。

说“安装哔哩哔哩官方 Android 客户端”会显示安装预览。确认后由电视自行下载 32 位官方 APK，校验发布证书和包名，交给系统安装并独立核对安装版本。“打开 B 站”指向 `tv.danmaku.bili`。

“打开 B 站搜索星辰亻旅行者”是一次站内搜索。星仪把原搜索词交给官方客户端，并检查结果页上的搜索词和结果卡片。小爱明确无法执行时，星仪可从同一轮原话自动接手。首次使用需要在客户端处理用户协议。

点歌可以只说歌名。网易云曲库把《空心》收录为光泽的同名曲，也收录了黄霄雲与刘端端合唱的《空心 (Live版)》。指定任一演唱者时，星仪按完整署名查找并核对播放器。明确要求原版或独唱时会保留版本约束。

## 一次唤醒后自动接手

小爱判断无法执行后，星仪核对同一轮原话和失败答复，通过本机 MCP 交给 harness。常见的明确拒绝可以在小爱还未播完时接手，其他受支持的拒绝由原有的会话检查处理。每轮只提交一次。小爱正常完成的请求由它自行回答。

在「小爱自动接手」中可开启或恢复拒绝播报。开启时，星仪在小爱的播放器确认开始播放已知拒绝话术后请求中止这一句。电视总音量不变，有时仍可能听到开头。harness 完成后通过小爱朗读结果，点歌以网易云实际返回的歌手与曲名为准。需要人工确认时先读确认提示。过长的结果会缩短朗读，完整内容保留在星仪界面。[0.9 真机验收](../VERIFICATION-0.9.md)

开启「小爱自动接手」后，日常照常喊“小爱同学”。例如问“你能读取星仪助手内部的本机休眠定时吗？”小爱先处理，星仪在电视上对照同一轮识别原文和拒绝答复。命中后通过本机 MCP 递交完整原文，查询自动继续。整条路无需电脑常开。

点歌时说“小爱同学，打开网易云音乐播放林俊杰的《不为谁而作的歌》”。当一句话明确指定了网易云、歌手和歌名，小爱却答复要换用其他音乐源时，星仪会自动调用点歌工具，在电视版网易云里播放并核对曲目信息。小爱已在网易云播对时不会重播。这条点歌流程无需再次确认，其他设备操作沿用原有确认规则。[0.8 真机点歌记录](../VERIFICATION-0.8.md)

小爱有时通过语音指令标注“不支持”，有时只在屏幕卡片回答无法读取。只有符合规则的单一意图会转交。正常结果、不完整答复、混合任务、权限或安全限制、网络错误以及超时都会保持原样。星仪本身能否完成，还取决于已安装工具和模型线路。

也可以只点歌手，例如“小爱同学，网易云音乐打开周杰伦的歌”。小爱明确拒绝后，星仪按曲库可播性选一首，优先考虑独唱，也可以播这位歌手第一署名的合唱。说出具体歌名时仍按歌名和完整歌手署名核对。[周杰伦点歌真机记录](../VERIFICATION-0.8.1.md)

「小爱自动接手」是一次性的设备设置，同一小米账号在电视上的新会话都会参与本地判定。明确拒绝的原话可转交 MCP。上述点歌由本机工具执行，无需模型；若网易云新开始播放同名的其他演唱版本，星仪也会核对当前请求和播放会话再决定是否纠正。在星仪左侧可关闭「小爱自动接手」，关闭后删除本机保存的接手账号配置。[0.7 查询接手记录](../VERIFICATION-0.7.md)

## 也可以明确转交给 MCP

平常直接用小爱。要检查本机接力，可试“小爱同学，打开星仪查音量这个应用”。真机已从小米的原厂文字入口验证此口令会拉起独立应用并实际调用 MCP；普通的“打开电视设置”由小爱完成。

在 Windows 桌面「星仪电视语音遥控器」里，说话或输入后先点「先交给小爱」。小爱明确表示没有执行时，点「小爱说做不了，交给 MCP」，同一句原文会进入星仪，涉及设备操作时会先显示预览。电脑需连接家庭网络。没有回复或状态不明时先查看设备；程序不会因超时自动重发。电视固件没有向星仪开放全局未命中回调，直接在房间里说的上一句话也不会出现在电脑遥控器里。

## 操作

- 进入桌面的「星仪电视助手」。遥控器方向键选择，确定键操作。
- 输入问题后选「发送」，模型为 `MiniMax-M3.1-Flash`。请求先发给 MiniMax 官方 API，官方线路不可用时自动改走备用网关。回答区上方的状态行写明本次由哪条线路应答及原因，例如「已完成 · 备用网关应答 · 官方余额不足，17:18 后重试」。规则见下文「模型线路」。
- 试试「现在音量是多少」：模型会调用工具读取电视状态，再根据读数回答。「把音量设成 18」会先预览，按遥控器确定键确认后才会改动。
- 左侧快捷按钮可直接控制媒体音量、静音、HDMI、应用、设置及桌面。「打开摄像头」经确认交给电视小爱。
- 「看当前屏幕」：确认后临时隐藏助手，只截一张画面，发送给模型分析。使用电视自己的 127.0.0.1 ADB，无需电脑常驻。HDMI/受保护画面可能失败。截图内容不能生成可执行动作。
- 「朗读回答」：调用电视原有小米播报入口。
- 「交给小爱」：把输入框中的原文交给电视小爱，先显示确认。它沿用小爱当前的账号和能力；星仪只有请求派发状态，不知道米家设备是否执行成功。
- 「定时休眠」：15/30/60分钟或取消。电脑无需保持连接。重启电视后不保留定时。

## 模型线路

| 顺序 | 线路 | 接口 | 密钥来源（电脑注册表 HKCU\Environment） |
|---|---|---|---|
| 1 | 官方 MiniMax | `https://api.minimax.io/v1/chat/completions` | `MINIMAX_API_KEY`，用户自己的 MiniMax 密钥 |
| 2 | 备用网关 | `https://gateway.example.com/v1/chat/completions` | `GATEWAY_API_KEY` |

两条线路使用同一个模型和同一套原生工具调用。官方线路出现线路级故障时才改走网关：余额不足（HTTP 402 / 1008）、鉴权失败（401 / 1004）、HTTP 5xx、超时或网络不通。参数错误、内容审核、限流、回答格式错误和工具执行失败照常报错，不会悄悄换线路。

余额不足或鉴权失败后，官方线路暂停 10 分钟，期间直接使用网关，不再逐次请求官方。暂停记录保存在应用私有目录，应用重启后仍然有效。暂停结束后的第一个请求会重新尝试官方线路，所以充值后最多 10 分钟就会自动回到官方，无需重新配置。同一轮对话一旦改走网关，后续的工具循环也留在网关。

这把密钥只能在国际站 `api.minimax.io` 鉴权，中国站 `api.minimaxi.com` 返回 401。官方没有名为 `MiniMax-M3.1` 的模型（返回 400 / 2013），M3.1 指 `MiniMax-M3.1-Flash`。

## 语音与网易云点歌

家里的普通遥控器可以用方向键选输入框旁的「手机语音」。手机连同一 Wi-Fi，在浏览器打开电视显示的地址，输入八位配对码，点手机输入法的麦克风说话。核对文字后提交，电视会显示操作预览，按遥控器确定键执行。配对两分钟有效，每次接收一条指令。

在已配对的电脑上，双击桌面「星仪电视语音遥控器」，选麦克风，点「开始说话」。例如说“打开网易云音乐，播放林俊杰的不为谁而作的歌”。核对识别文字后点「发送到电视」。电脑窗口会显示本次请求具体要做的事，可以在电脑上确认或取消。电脑与电视需在同一网络。语音由电脑本地的 Whisper large-v3-turbo 处理，发送给电视的是文字。[桌面入口实现](voice_remote.pyw)

点歌会向网易云查询曲目编号，打开电视版网易云，再核对它报告的播放状态、歌名、歌手和专辑。可以指定歌手和歌名，也可以只点歌手。在线播放取决于网易云可提供的版本及账号权限。

## 当前限制

2026-11-03 官方 MiniMax 账户余额不足：官方 API 对每个请求返回 HTTP 402 / 1008，目前由备用网关应答。到 MiniMax 控制台充值后会自动切回官方。网关偶尔看错图片：同一张纯绿测试图，4 次中有 1 次答成白色。

内置麦克风确实存在，小爱仍可正常唤醒。第三方录音/ASR被本机厂商签名白名单拦截，星仪没有实现自定义唤醒词或连续录音。不要把TTS/小爱文字转交当成星仪语音识别已完成。

视频搜索只使用应用公开入口，不保证跨平台自动播放。米家已按用户指令验证打开摄像头：播放器收到首帧并进入实时播放；其他设备尚未逐一验证，无直接设备状态读回。ADB授权撤销或网络调试关闭会使截屏和定时休眠不可用。模型线路及厂商云服务需要网络。

## 构建与配置

在 Git Bash 执行 `bash H:/tools/mitv/voice/assistant/build.sh` 得到正式包 `build/xingyi.apk`；`bash build.sh debug` 得到同包名、同版本号、同签名的 `build/xingyi-debug.apk`，只在导入配置时临时使用。无Gradle；Android SDK和JDK沿用原Orrery构建环境。

两条线路的地址、模型和密钥写在电视应用私有 `files/config.json`（第 2 版，含 `official` 与 `gateway` 两项），不在源码、APK 或共享目录中。0.4 的单网关配置仍能读取，此时只走网关，状态行显示「官方未配置」。ADB密钥也是本机自生成、仅在应用私有目录保存；没有复制电脑ADB私钥。正式包 `debuggable=false`、`allowBackup=false`，两条线路都只允许HTTPS，官方线路只接受 MiniMax 官方域名。

重新导入配置：先构建两个包，再执行 `python provision_minimax.py --report ../evidence-0.5/provision.json`。脚本从注册表读取两把密钥，只经 adb 标准输入写入电视，不打印，不放进命令行参数，也不写电脑文件。步骤如下：

1. 核对两个包与电视上已安装的版本包名、版本号和签名证书一致，记下首次安装时间。
2. 用 debug 包覆盖安装（数据保留），列出全部私有文件的权限、大小和 SHA-256。
3. 把 `files/`、`shared_prefs/` 复制到应用私有目录 `no_backup/provision-backup` 并逐个核对。
4. 写入配置，再次列出私有文件。除 `files/config.json` 外必须逐字节一致，包括本机 ADB 身份 `files/xingyi-adb-key.pk8`；新配置的哈希必须等于发送内容。
5. 装回正式包，确认不可调试、`run-as` 被拒、首次安装时间不变。

任何一步不符，脚本会从备份恢复原配置，再装回正式包。备份留在应用私有目录，下次导入时覆盖，卸载应用时一并删除。旧的 `provision_gateway.py` 已停用，它只会写单网关配置。卸载应用会丢失配置和本机ADB身份。

`restore-assistant.ps1` 位于父目录，可卸载星仪助手，不动Orrery或小爱。
